# Changelog

## 0.2.0 — 2026-11-13

Initial public release: local call transcription, interview mode, live speaker
labels, optional cloud transcription, recovery, and Markdown export.

Prepared for public distribution with AGPL-3.0-or-later licensing, third-party
notices, anonymous release downloads with SHA-256 verification, sanitized test
fixtures/build paths, and documented privacy/security boundaries.

The earlier private v0.2.0 build and its Git history were replaced before
publication. Existing private checkouts must re-clone; do not merge old history.
